### 💻 Proyecto Frontend (React)

Este repositorio también cuenta con un cliente web construido en **React + Vite** que se conecta directamente a la API.

#### 🚀 Instrucciones rápidas

1. Ir a la carpeta del frontend:
```bash
cd test.university.webclient
```

---

2. Instalar dependencias:
```bash
npm install
```

---

3. Inicia proyecto
```bash
npm run dev
```

---

#### ✅ Asegúrate de que el backend esté corriendo en https://localhost:7175 o https://localhost:5250 para permitir la autenticación y consumo de datos desde la API.
